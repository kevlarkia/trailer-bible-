# Phoenix Crown 3D Interactive Model

This directory contains the Phoenix Flame Crown 3D interactive model viewer.

## File

- `phoenix-crown-3d.html` - A standalone HTML file featuring an interactive 3D model of the Phoenix Flame Crown

## Features

The 3D model includes:
- **Interactive 3D visualization** using Three.js
- **Detailed crown model** with 162 carats of precious gemstones
- **Multiple view modes**: Solid, Wireframe, and Gems Only
- **Preset camera views**: Front, Side, and Top
- **Auto-rotation** with manual control
- **Mouse controls**: Click and drag to rotate, scroll to zoom
- **Detailed specifications** panel showing gemstone information

## Crown Specifications

- **Height**: 9.5 inches
- **Base Diameter**: 6.75 inches
- **Metal**: 18K Yellow Gold
- **Weight**: ~1050g
- **Total Gemstones**: 48 stones (162ct total)
  - Pigeon Blood Ruby: 64ct
  - Rhodolite Garnet: 2×12ct
  - Golden Topaz: 4 stones (~72ct)
  - Cubic Zirconia: 40 stones (~2ct)

## Usage

Simply open `phoenix-crown-3d.html` in a modern web browser. The model will load automatically with no additional setup required.

### Browser Requirements

- Modern browser with WebGL support (Chrome, Firefox, Safari, Edge)
- JavaScript enabled
- Internet connection (for loading Three.js library and fonts)

## Controls

- **Mouse drag**: Rotate the crown
- **Mouse wheel**: Zoom in/out
- **View Mode buttons**: Switch between Solid, Wireframe, and Gems Only views
- **Preset Views**: Quick camera positioning (Front, Side, Top)
- **Auto-Rotate button**: Toggle automatic rotation on/off
